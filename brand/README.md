# هوية «سمرة»

لعبة جمعات مستقلة (مسيرة · اسمعها · من فينا؟). اتجاه الهوية: **سدو**، ألوان داكنة مريحة للعين.

**الألوان:** ليل `#1C1816` · خيمة `#26201D` · صوف `#E9E1D3` · ذهبي `#C9934A` · أحمر السدو `#A8473B` · فحمي `#120F0E`
**الخطوط (OFL مجانية):** Reem Kufi 700 للعناوين، Almarai للنصوص.
**الشعار:** الحروف من Reem Kufi محوّلة لمسارات SVG، ما يحتاج الخط.

اسم المتجر المقترح: «سمرة: لعبة الجمعات» لأن «سمرة samara» مأخوذ (تطبيق فعاليات) — تحقق 2026-11-13.

`src/` فيه سكربتات توليد الملفات: `gen.py` (تحويل الخط لمسارات، يحتاج fonttools + uharfbuzz وملف ReemKufi-700.ttf)، `comp.py` (تركيب الشعارات والأيقونة)، `png.js` (تصدير PNG بـ Playwright)، `guide.py` + `guide_tpl.html` (دليل الهوية).
