# سمرة

لعبة جمعات سعودية: جوال واحد يدور بالمجلس أو ينعرض على التلفزيون. ثلاث أطوار: **مسيرة** و**كم تتوقع؟** و**من فينا؟**

- وثيقة التصميم: https://claude.ai/artifact/NCojKHq631VK9pwz8Gza1j
- دليل الهوية: `brand/brand-guide.html`

## الحالة

**المرحلة ٢: الثلاث ألعاب شغالة.** مسيرة (٥٠٠ بطاقة)، كم تتوقع؟ (١٠٥ سؤال جوابها رقم، والأقرب ياخذ النقاط)، ومن فينا؟ (كل لاعب يجاوب ٥ أسئلة بالسر من ٦٠ سؤال). نفس النقاط والفرق (٢ إلى ٤)، «بالدور» و«سرعة»، النقاط المضاعفة، الجولة الفاصلة، الحفظ والاستكمال، وتعديل النقاط يدويًا.

## التشغيل

رابط التجربة: https://37azezazez-web.github.io/samra-game/

أو افتح `index.html` بالمتصفح مباشرة، ما يحتاج تثبيت أي شي.

```
npm test        # اختبارات المحرك والمحتوى و5000 سهرة عشوائية (Node 22)
npm run e2e     # فحص المتصفح والأمان (يحتاج Playwright)
```

## الملفات

| الملف | وش فيه |
|---|---|
| `js/engine.js` | منطق السهرة والنقاط، بدون شاشات (يتختبر بـ Node) |
| `js/cards.js` | بطاقات مسيرة والفئات |
| `js/numbers.js` | أسئلة كم تتوقع؟ |
| `js/guess.js` | منطق كم تتوقع؟ ونقاطها |
| `js/who.js` | أسئلة من فينا؟ |
| `js/app.js` | الشاشات والأزرار والحفظ |
| `css/style.css` | الشكل، والألوان من الهوية |
| `assets/fonts/` | Reem Kufi وAlmarai (رخصة OFL، مجانية) |
| `brand/` | ملفات الهوية وسكربتات توليدها |
| `CONTENT-REVIEW.md` | قائمة مراجعة معلومات البطاقات |
| `reports/` | تقارير فحص الأمان والثبات |

## إضافة بطاقة

بـ `js/cards.js` أضف سطر بنفس الشكل: `id` فريد، `cat` من الفئات، `answer`، و٥ `clues` من الأصعب للأسهل. شغّل `npm test` يتأكد إن كل بطاقة فيها ٥ تلميحات وإن الجواب مو مكتوب داخل التلميحات.
