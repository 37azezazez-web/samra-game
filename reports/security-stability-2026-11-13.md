# فحص الأمان والثبات · 13 نوفمبر 2026

**النتيجة:** كل الفحوصات نجحت. ما لقيت ثغرة، وما فيه حالة تعلق فيها اللعبة.

## الأمان

| البند | الحالة |
|---|---|
| أسماء الفرق (المدخل الوحيد من المستخدم) | تنعرض كنص فقط. جربنا أكواد مثل `<img onerror>` وما انفذت |
| سياسة أمان المحتوى (CSP) | مفعّلة: ما يشتغل إلا كود اللعبة نفسها، بدون كود داخل الصفحة، بدون نماذج ولا إطارات |
| الطلبات الخارجية | صفر. الخطوط والصور كلها داخل اللعبة، وما فيه تتبع ولا إعلانات |
| البيانات الشخصية | ما تنجمع. السهرة تنحفظ بذاكرة الجوال بس |
| الحفظ المتلاعب فيه | اللعبة تفحص الحفظ قبل ما تكمله، وأي شي غريب ترجع للرئيسية |
| تشغيل بدون إنترنت | فقط ملفات اللعبة نفسها تنخزن، وأي ملف خارجي يتجاهل |
| مكتبات خارجية | ما فيه ولا مكتبة، فما فيه ثغرات مكتبات |
| الأسرار وكلمات المرور | ما فيه أي مفتاح أو كلمة سر بالكود |

**حدود معروفة:** GitHub Pages ما يسمح نضيف ترويسات أمان من السيرفر (مثل منع عرض الموقع داخل إطار). الخطر قليل لأن اللعبة ما فيها حسابات ولا بيانات حساسة. لما تنزل كتطبيق آيفون هالنقطة تنحل تلقائيًا.
